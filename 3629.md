[Problem: 3629. 通过质数传送到达终点的最少跳跃次数](https://leetcode.cn/problems/minimum-jumps-to-reach-end-via-prime-teleportation/description/)

### 方法：BFS

从起点 $0$ 到终点 $n-1$，还是我们的老朋友 **“最短路径问题”**。

- **相邻移动**： $i \to i+1$ 和 $i \to i-1$。权重为 $1$。
- **质数传送**：如果 $nums[i]$ 是质数 $p$，则可以跳到任何满足 $nums[j] \% p = 0$ 的下标 $j$。权重为 $1$。

相邻跳跃很好理解，质数传送能到达哪里？

仔细观察规则 $2$，可以发现：传送的起点必须是质数，**而终点只需要是倍数**。因此，想到去关注数字的 **质因子结构**。

我们需要快速知道 $nums[i]$ 是否为质数，以及每个数字包含哪些质因子。

使用 **埃氏筛** 预计算出一个最小质因子 $minPrime$ 数组。

- 通过 $minPrime[x] = x$ 可以 $O(1)$ 判断 $x$ 是否为质数。
- 通过 $minPrime$ 可以 $O(\log(nums[i]))$ 时间对任意数进行质因数分解。

具体的原理/模板，请看这篇 [题解](https://leetcode.cn/problems/find-the-count-of-numbers-which-are-not-special/solutions/2996915/shu-xue-shu-xue-zheng-ming-qian-zhui-he-mfevi/)。

现在，我们已经将质数处理完，那它能跳到哪里？

因此，需要建立 **“质数 -> 下标清单”** 的映射。定义 $primeToIdx[p]$ 存储所有包含质因子 $p$ 的下标 $j$。比如质因子 $3$ 对应的倍数有 $[6,9]$，下标为 $[2,4]$。

**关键点**：每个质数 $p$ 的清单只需 **预处理一次**。一旦处理过，之后再次遇到相同的质数，不需要 **重复遍历**，因为最短路径已经保证了第一次到达时步数最少。

具体来说，维护一个访问标记 $visitedIdx$，防止下标重复访问；以及维护一个 $visitedPrimes$ 集合，防止同一个质数的重复传送。

**在每一层 $BFS$ 中**：

- 从队列中弹出当前下标 $curr$。
- 尝试相邻移动： $curr-1$ 和 $curr+1$。
- 尝试质数传送：如果 $nums[curr]$ 是质数 $p$，且 $p$ 未被访问过：
  - 遍历 $primeToIdx[p]$，将未访问的下标加入队列。
  - 标记 $p$ 为已访问。
- 当第一次遇到终点 $n-1$ 时，返回当前的步数。

代码如下，已附加注释：

```Python
# python
class Solution:
    def minJumps(self, nums: List[int]) -> int:
        n = len(nums)
        mx = max(nums)
        
        # 埃氏筛，预计算最小质因子
        min_prime = list(range(mx + 1))
        for i in range(2, int(mx**0.5) + 1):
            if min_prime[i] == i:
                for j in range(i*i, mx + 1, i):
                    if min_prime[j] == j:
                        min_prime[j] = i
        
        def is_prime(x):
            return x > 1 and min_prime[x] == x
        
        # 建立 “质因子 -> 下标列表” 的映射
        prime_to_indices = defaultdict(list)
        for i, x in enumerate(nums):
            temp = x
            # 寻找 x 的所有质因子
            while temp > 1:
                p = min_prime[temp]
                prime_to_indices[p].append(i)
                while temp % p == 0:
                    temp //= p
        
        # BFS
        queue = deque([0])
        visited_idx = [False] * n
        visited_idx[0] = True
        visited_primes = set()
        step = 0
        
        while queue:
            for _ in range(len(queue)):
                curr = queue.popleft()
                # 到达终点
                if curr == n - 1:
                    return step
                
                # 相邻移动
                for neighbor in [curr - 1, curr + 1]:
                    if 0 <= neighbor < n and not visited_idx[neighbor]:
                        visited_idx[neighbor] = True
                        queue.append(neighbor)
                
                # 质数传送
                val = nums[curr]
                if is_prime(val) and val not in visited_primes:
                    visited_primes.add(val)
                    for neighbor in prime_to_indices[val]:
                        if not visited_idx[neighbor]:
                            visited_idx[neighbor] = True
                            queue.append(neighbor)
            step += 1
        
        return -1
```

```Java
// java
class Solution {
    public int minJumps(int[] nums) {
        int n = nums.length;
        if (n <= 1) return 0;
        
        int mx = 0;
        for (int x : nums) {
            mx = Math.max(mx, x);
        }
        
        // 埃氏筛，预计算最小质因子
        int[] minPrime = new int[mx + 1];
        for (int i = 0; i <= mx; i++) {
            minPrime[i] = i;
        }
        for (int i = 2; i * i <= mx; i++) {
            if (minPrime[i] == i) {
                for (int j = i * i; j <= mx; j += i) {
                    if (minPrime[j] == j) {
                        minPrime[j] = i;
                    }
                }
            }
        }
        
        // 建立 “质因子 -> 下标列表” 的映射
        List<Integer>[] primeToIndices = new ArrayList[mx + 1];
        for (int i = 0; i < n; i++) {
            int temp = nums[i];
            // 寻找 x 的所有质因子
            while (temp > 1) {
                int p = minPrime[temp];
                if (primeToIndices[p] == null) {
                    primeToIndices[p] = new ArrayList<>();
                }
                primeToIndices[p].add(i);
                while (temp % p == 0) {
                    temp /= p;
                }
            }
        }
        
        // BFS
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        boolean[] visitedIdx = new boolean[n];
        visitedIdx[0] = true;
        boolean[] visitedPrimes = new boolean[mx + 1];
        int step = 0;
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                
                // 到达终点
                if (curr == n - 1) {
                    return step;
                }
                
                // 相邻移动
                int[] neighbors = {curr - 1, curr + 1};
                for (int neighbor : neighbors) {
                    if (neighbor >= 0 && neighbor < n && !visitedIdx[neighbor]) {
                        visitedIdx[neighbor] = true;
                        queue.offer(neighbor);
                    }
                }
                
                // 质数传送
                int val = nums[curr];
                // is_prime(val) 逻辑：val > 1 && min_prime[val] == val
                if (val > 1 && minPrime[val] == val && !visitedPrimes[val]) {
                    visitedPrimes[val] = true;
                    List<Integer> targets = primeToIndices[val];
                    if (targets != null) {
                        for (int neighbor : targets) {
                            if (!visitedIdx[neighbor]) {
                                visitedIdx[neighbor] = true;
                                queue.offer(neighbor);
                            }
                        }
                    }
                }
            }
            step++;
        }
        
        return -1;
    }
}
```

- 时间复杂度： $O(mloglogm+nlogm)$，其中 $n$ 是数组 $nums$ 长度，而 $m$ 是数组中的最大值。埃氏筛时间为 $O(mloglogm)$，建立映射时间为 $O(nlogm)$，在 $BFS$ 中每个下标最多入队一次，每个质数的索引列表最多被完整遍历一次，时间为 $O(nlogm+n)$
- 空间复杂度： $O(m+nlogm+n)$，分别表示数组 $minPrime$，哈希 $primeToIdx$，队列以及标记数组的大小
